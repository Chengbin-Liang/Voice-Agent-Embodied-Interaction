## 🧭 A minimal evaluation suite

| Goal | Suggested combination | Report separately |
|---|---|---|
| General / Chinese voice assistant | [VoiceBench](CATALOG.en.md#e59) + [VCB Bench](CATALOG.en.md#e61) | Content capability, instruction following, and robustness |
| Continuous full-duplex chat | [Full-Duplex-Bench](CATALOG.en.md#e16) + [MTR-DuplexBench](CATALOG.en.md#e65) | Turn-transition / interruption timing and multi-turn quality |
| Voice agent that executes tools | [VoiceAgentBench](CATALOG.en.md#e62) + [Full-Duplex-Bench-v3](CATALOG.en.md#e64) + [τ-Voice](CATALOG.en.md#e63) | Function arguments, calls under disfluent speech, and environment final-state success |
| Controllable, proactive, or multi-party interaction | [Instruct-FD](CATALOG.en.md#e69) / [DuplexAct-Bench](CATALOG.en.md#e70) + [MP-Bench](CATALOG.en.md#e67) / [Duplex-MPE](CATALOG.en.md#e68) | Following instructions, timely participation, and appropriate silence |
| End-to-end business voice-system experience | [EVA-Bench](CATALOG.en.md#e71) + fixed human tasks | Task accuracy, experience, end-to-end latency, and failure recovery |

## 📐 Conditions to retain when comparing results

1. **Latency definition:** record acoustic gaps, model inference time, and end-to-end latency including networking and playback separately.
2. **Causal inputs:** an online system can only see audio already received at that moment; report offline replay and real-time service results separately.
3. **Success levels:** distinguish correct function names/arguments, actual tool execution, successful environment final states, and the user hearing correct feedback.
4. **Experimental protocol:** fix the model, prompt, tool environment, data split, simulated user, judge, and number of runs. Do not interchange pass@k with metrics for consistent success across repeated trials.
5. **Generalization scope:** report synthetic speech, human recordings, and live human interaction separately. Multi-party interaction, noise, accents, long conversations, and interruption recovery need corresponding evidence.

Embodied tasks also require recording action completion, correct target selection, effective cancellation, and human takeover. These voice benchmarks cannot directly replace [robot and human-collaboration evaluations](04-Edge-Embodied-Interaction.en.md).
