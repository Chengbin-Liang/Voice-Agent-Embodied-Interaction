<summary><strong>🏷️ Reading labels, Stars, and Cites</strong></summary>

- **⭐ Read first** identifies useful conceptual or reproduction starting points, with reasons. Other entries are not ranked.
- **Academic / Industry / Academic + Industry / Independent Lab** follows paper affiliations or project maintainers and links to the source.
- **Venue** links to proceedings, journals, or author pages. arXiv denotes a preprint record; Project / Technical Demo denotes a project or demonstration. Author-reported acceptance is identified as such.
- **Star / Cite** counts are snapshots from 2026-11-02 to 2026-11-03, dated per entry. OA = OpenAlex; S2 = Semantic Scholar. Counts are not added together, missing values are not zero, and shared-repository stars belong to the whole repository. Counts are reference aids only.
